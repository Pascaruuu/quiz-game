# 日本語のクイズゲーム

このプロジェクトは日本語プログラムの4班が　「SvelteKit」や「TypeScript」を使って、開発られました。

ゲームのプロジェクトです。ゲームで英語の言葉を表示し、日本語の4つの言葉の選択があります。選んだ答えの一つを選べたら、100点を受けられます。

## Live URL

このゲームのプロジェクトはバーセルでデプロイられました：
https://quiz-game-hsl7ci04k-pascaruuus-projects.vercel.app/

## 前提条件

- Node.js 18+
- npm

## データベースのセットアップ

プロジェクトを実行するように：

1. Tursoアカウントを作成する
2. プロジェクトの利用ため、データベースを作成する
3. 0000_magenta_storm.sqlというファイルであるQueryを使って、テーブルを作成する
4. .env.exampleというファイルでテンプレートを利用し、シクレとを書く

## 依存のインストール

このSvelteKitアプリを実行するために、下の指示を進めてください：

```sh
# プロジェクトのルートフォルダーのターミナルでこのコマンドを実行してください
npm install
```

## 開発モードで実行する

To run this project in localhost, follow the following instruction:
ローカルホストでこのプロジェクトを実行するために、下の指示を進めてください

```sh
# プロジェクトのルートフォルダーのターミナルでこのコマンドを実行してください
npm run dev
```

## 画面

1. **ホームページ画面**: この画面ではBGMや動く背景が付けています。

2. **名前入力画面**: この画面はユーザー名を入力するためです。

3. **ゲーム画面**: ここではユーザーが日本語の単語として、ゲームができます（正解の答えを選んだら、100点をスコアに追加します）。

4. **結果画面**: この画面では、スコア、正解や間違い答えが付けています。リプレイやリーダーボードページに行くこともできます。

5. **リーダーボード画面**: この画面では10つの上のスコアやそのスコアと対応するユーザーを表示する。

6. **Credit 画面**: ここではこのプロジェクトの開発者やその貢献を表示する。
